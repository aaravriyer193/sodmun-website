# SODMUN website

The website for Summit of Diplomacy Model United Nations. It's a static site with no build step.

- Live: https://sodmun.vercel.app
- Content (committees, secretariat, partners, schedule, application links): `js/data.js`
- Styles: `css/site.css`

## Build

`tools/build.js` pre-renders the data-driven sections into the HTML (so crawlers
see them without JavaScript) and regenerates every `<head>`, `sitemap.xml`,
`robots.txt` and `site.webmanifest`. Run it after editing `js/data.js` or a page body:

```bash
node tools/build.js
```

Set `SITE_URL` at the top of that file when the site moves to its final domain.

Share images are generated by `tools/og.py` (needs Pillow):

```bash
python3 tools/og.py
```

## Run locally

```bash
python3 -m http.server 4340
```

## Deploy

```bash
vercel deploy --prod
```
